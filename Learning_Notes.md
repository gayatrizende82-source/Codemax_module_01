# Codomax Module 01 – Introduction to AI & Python

## 1. Artificial Intelligence (AI)
Artificial Intelligence is a branch of computer science that enables machines to perform tasks that normally require human intelligence, such as understanding language, recognizing images, and making decisions.

**Examples:** voice assistants, face unlock, chatbots, and recommendation systems.

## 2. Machine Learning (ML)
Machine Learning is a part of AI in which computers learn patterns from data and use those patterns to make predictions or decisions without being explicitly programmed for every situation.

**Examples:** spam email detection, movie recommendations, and fraud detection.

## 3. Deep Learning (DL)
Deep Learning is a part of Machine Learning that uses multi-layered artificial neural networks to learn complex patterns from large amounts of data.

**Examples:** image recognition, speech recognition, and some self-driving car systems.

## 4. Difference between AI, ML and Deep Learning

| Term | Meaning | Relationship |
|---|---|---|
| AI | Machines performing tasks that require human-like intelligence | Broadest field |
| ML | Systems learn patterns from data | Subset of AI |
| Deep Learning | Uses multi-layer neural networks to learn complex patterns | Subset of ML |

## 5. Real-world applications of AI
- **Healthcare:** helping analyze medical images and supporting diagnosis.
- **Education:** personalized learning recommendations.
- **Banking:** detecting unusual transactions and possible fraud.
- **Shopping:** product recommendations.
- **Transport:** route and traffic predictions.
- **Agriculture:** detecting crop problems from images.

## 6. Python basics

### Variables
A variable is a named location used to store a value.
```python
student_name = "Gayatri"
age = 20
```

### Common data types
- `int`: whole numbers, for example `10`
- `float`: decimal numbers, for example `10.5`
- `str`: text, for example `"Hello"`
- `bool`: `True` or `False`

### If-else
An if-else statement makes a decision based on a condition.

### Loops
A loop repeats a block of code. A `for` loop is commonly used to iterate over a sequence. A `while` loop repeats while its condition is true.

### Functions
A function is a reusable block of code that performs a specific task. It is defined using `def`.

### Lists
A list stores multiple items in one variable. Lists are written using square brackets, for example `["Apple", "Banana"]`.

## 7. How to run the Python programs
1. Open the project folder in VS Code.
2. Open a `.py` file.
3. Click the Run button, or open Terminal > New Terminal.
4. Run: `python filename.py`
5. For input-based programs, enter the requested values in the terminal.
